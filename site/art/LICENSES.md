# Art licences

Every file in this folder is original work made for the studio.

- `tile-*.svg` (the 12 game tiles plus `tile-maths.svg` and `tile-english.svg`): drawn by hand as SVG code for the studio. No AI image generation, no Figma generation, no stock, no traced or third-party images.
- The small icons (`<name>.svg`, for example `snake.svg`) are also original studio work.

All files may be used, changed and replaced by the studio. Names are stable so that later art can replace a file by name with no code change.

## brand/ (Active Mind Craft business logos)

`brand/logo-horizontal-{light,dark}.svg` (exactly 5:1, 800 x 160) and `brand/logo-vertical-{light,dark}.svg` (3:4, 300 x 400):
three overlapping circles, one per word (Active, Mind, Craft), each holding its letter, with a gold spark where they meet, and
the name beside (horizontal) or below (vertical). The drawing and layout are original work made for the studio; no AI generation.
The letters are outlines of Nunito ExtraBold (SIL Open Font License 1.1, the font already bundled in
`game-factory/.../design/fonts/`), converted to paths so the files need no font. Trademark search not done.
Earlier versions (bulb and stack) are saved in `design/logo-archive/`.
